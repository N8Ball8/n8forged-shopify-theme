# Changelog

All notable N8Forged theme changes will be documented here. Versions follow
[Semantic Versioning](https://semver.org/).

## [Unreleased]

## [0.4.1] - 2026-08-15

### Fixed

- Displayed the selected or first available variant price on homepage product cards.

## [0.4.0] - 2026-07-29

### Added

- Live mission art auction with proxy bidding, bid history, reserve status, and winner handling.
- Mission donation page, support paths, social sharing, and campaign tracking.
- Direct-link hidden product support for custom product offerings.
- Detailed artwork hotspot images and mission-focused storefront assets.

### Changed

- Completed the Costa Rica mission homepage, navigation, product collection, and responsive layouts.
- Added concise, unique search descriptions across products and key landing pages.
- Changed product cards to use stable product URLs instead of variant-specific links.
- Kept policy pages, duplicate collections, unused news content, and hidden products out of search results.

### Fixed

- Corrected auction bidding behavior, timing history, and post-auction presentation.
- Restored product grids after hidden products are filtered.
- Improved product image selection, sharing previews, and mobile interface icons.

## [0.3.0] - 2026-07-14

### Added

- Costa Rica mission campaign homepage and campaign-specific content architecture.
- Provisional N8Forged header mark and expanded forged storefront styling.

### Changed

- Aligned storefront accents with the approved N8Forged blue.
- Tightened campaign hero spacing and responsive composition.

### Fixed

- Kept the newsletter footer below long product galleries and product controls.

## [0.2.0] - 2026-07-14

### Added

- Weekly non-destructive Horizon upstream monitoring.
- Monthly Shopify CLI and GitHub Actions dependency maintenance.
- GitHub Actions checkout v7 across automated workflows.

## [0.1.0] - 2026-07-14

### Added

- Official Shopify Horizon 4.1.1 theme baseline.
- GitHub-connected production and development themes.
- Protected `main` and `development` branches.
- Automated Theme Check validation for pull requests.
- Repeatable local validation and preview commands.
- Development, release, rollback, and architecture-decision documentation.
